# Basatine Architectural Offer

GitHub Pages-ready static website.

## Upload

1. Upload every file and the complete `assets` folder to the root of a GitHub repository.
2. Open the repository's **Settings** and select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

The website entry point is `index.html`. Keep the folder structure unchanged so the images, PDFs, styles and interactions continue to work.
